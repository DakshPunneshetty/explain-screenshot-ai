# Explain Screenshot AI

Explain Screenshot AI is a simple AI-powered tool that helps users understand content directly from screenshots.

Users can upload a screenshot of a question, paragraph, or problem. The application extracts text from the image using OCR and uses a large language model to provide clear explanations or concise summaries.

The app also includes multiple explanation levels, allowing the AI to explain concepts like a tutor depending on the user’s needs.

### Features

* Upload screenshots of text, questions, or notes
* Automatic text extraction using OCR
* AI-powered explanations
* Multiple explanation levels (simple to detailed)
* Quick summarisation of extracted content
* Clean and interactive interface built with Streamlit

### Tech Stack

* Python
* Streamlit
* Tesseract OCR
* Groq LLM API

### Use Cases

* Understanding homework or textbook questions
* Explaining difficult paragraphs or concepts
* Quickly summarising screenshots of notes
* Learning with AI assistance

### How It Works

1. Upload a screenshot.
2. The system extracts text from the image using OCR.
3. The text is sent to an AI model.
4. The AI generates an explanation or summary for the user.

This project was built as an experiment in combining computer vision and AI to make learning from screenshots easier.
